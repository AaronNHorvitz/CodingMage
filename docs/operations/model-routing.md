# Model Routing

Routing is deterministic policy, not model self-selection. Work class, risk, failure history, review disagreement, required gate level, availability, and an optional stronger operator pin determine a profile. An operator may strengthen but not weaken or cross the configured provider boundary.

Routine implementation defaults to the configured general-purpose Claude profile and escalates after bounded failure. Security, architecture, concurrency, Git, process, and final verification use stronger configured profiles. Provider usage and reset values remain unknown when not measured.

No fallback silently weakens a required profile. An unavailable required profile blocks with a stable reason.
