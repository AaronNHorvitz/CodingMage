# Project Adapters

Markdown `TASKS.md` is the reference task source. A GitHub Issue adapter may load a bounded, content-addressed local snapshot containing exact remote identity and a separately reviewed canonical Markdown plan. Remote prose does not become authority directly.

Typed gate profiles exist for Rust, Python, Node, and documentation projects. A custom profile contains only absolute executables and literal argument vectors. Projects must declare expected relative artifacts and prohibited operations.

Repository, state, worktree, credential-reference, session, and evidence namespaces must be distinct within and across projects. Jira and Azure DevOps are future adapters and are not implemented.

Future host application requests and USTE context must enter through the boundaries in the
[integration requirements](../architecture/ecosystem-integration.md). Neither is a replacement for
the canonical task source or target authorization. Developing CodingMage with Muse Code is separate
from implementing a Muse worker adapter inside the product.
