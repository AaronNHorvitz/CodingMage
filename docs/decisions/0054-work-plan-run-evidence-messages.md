# ADR 0054: Catalogue Bound Work Plan Run Evidence

- **Status:** Accepted for an incremental native catalogue slice
- **Date:** 2026-10-01
- **Decision owners:** CodingMage implementation

## Context

The selected Work plan task already offers coordinator run evidence when its
campaign status and run-record projection are live and bound to the same head.
The labels inside that detail remained embedded English after the adjacent
source-detail catalogue migration.

## Decision

Use the existing validated English catalogue for the run-evidence disclosure,
exact-command label, stale and absent guidance, projection limits, run and
candidate identities, review and gate outcomes, and journal phases. Require
each dynamic identity, count and evidence field exactly once in its template.
Preserve the existing live-status binding, selection filter and bounded
projection. A journal integrity problem still withholds corroborated review
and gate claims. Test template mutation, missing versus uncorroborated outcomes,
and an expanded right-aligned run at the minimum window and double scale.

## Consequences

The coordinator command, parser, retained-record limits and authority do not
change. Other Changes and reviews copy, locale-specific numeric formatting,
full bidirectional navigation and installed screen-reader trials remain open.
A synthetic layout probe is local evidence only.
