# Release Notes

## 0.1.0 Candidate

Status: unreleased and unsupported.

The candidate line introduces the deny-first local coordinator, supervised one-unit workflow,
durable serial and bounded parallel campaigns, exact-commit independent review, content-minimized
recovery and monitoring, optional GitHub workflow adapters, reproducible Linux archive tooling, and
a rootless installation and user-service lifecycle. A native Linux desktop workspace
(`codingmage-ui`) over the coordinator binary exists with local, display-less verification only;
it is not packaged, and its desktop, accessibility, installation, live-provider and independent
review items remain open (see `docs/evidence/sprint-36-human-only.md`).

No public artifact exists. Fedora is the only platform with current local development evidence.
Ubuntu, Windows 11, authenticated provider and GitHub qualification, the final controlled pilot and
soak, manual fuzzing, independent review, operator signing, and publication remain open. See the
[release scope and risk register](docs/operations/release-scope.md).
